Viewcount Guessr

Einmalige Einrichtung

Folge diesen 4 Schritten — dauert ca. 3 Minuten. Danach funktioniert das Spiel dauerhaft und du musst nichts mehr einrichten.

1
GitHub-Account erstellen & Repository anlegen
Gehe auf github.com/signup und erstelle einen kostenlosen Account (falls noch nicht vorhanden).

Dann: github.com/new → Repository anlegen:
• Name: viewcount-guessr
• Visibility: Public ✓
• Klicke auf Create repository
2
index.html hochladen
Im leeren Repository auf uploading an existing file klicken → die index.html aus dem ZIP per Drag & Drop hochladen → Commit changes klicken.
3
GitHub Pages aktivieren
Im Repository: Settings → Pages (linke Sidebar) → unter Source wähle Deploy from a branch → Branch: main, Ordner: / (root) → Save.

Nach ~60 Sekunden erscheint deine URL:
https://DEIN-NAME.github.io/viewcount-guessr
4
Twitch Developer App erstellen
Öffne dev.twitch.tv/console/apps/create und logge dich ein.

Formular ausfüllen:
• Name: Viewcount Guessr
• OAuth Redirect URL: wird geladen…
• Kategorie: Website Integration → Erstellen

Dann: App → Verwalten → Client-ID kopieren → Neues Secret → Secret kopieren.
